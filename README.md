# Nmap Network Discovery Project

This project demonstrates network discovery and live host detection using Nmap in Kali Linux.

## Features
- Discover live devices on a network
- Save scan results
- Extract active hosts
- Automate scanning with Bash

## Tools Used
- Kali Linux
- Nmap

## Scan Type
- Ping Scan (-sn)

## Files
- discover.sh → automation script
- subnet.txt → target subnet
- ping_scan.txt → raw scan output
- live_hosts.txt → detected live systems
